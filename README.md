
# Etch-a-Sketch

A browser-based Etch-a-Sketch application built with HTML, CSS, and JavaScript as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.

## Live Demo

https://lhastbhorne.github.io/etch-a-sketch

## Features

- **Dynamic Grid:** Generate a grid with a custom number of squares per side.
- **Interactive Drawing:** Hover over individual squares to change their colours.
- **Random RGB Colours:** Each square receives a randomly generated RGB colour.
- **Progressive Darkening:** Each time you hover over a square, its colour becomes 10% darker.
- **Input Validation:** Grid size must be a whole number between 1 and 100.
- **Responsive Grid Generation:** The grid maintains a fixed 960 × 960 pixel area regardless of the number of squares.

## Built With

- HTML5
- CSS3 (Flexbox)
- JavaScript (DOM Manipulation and Event Listeners)

## How to Run Locally

1. Clone the repository:

   ```bash

   ```

2. Navigate into the project folder:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Open `index.html` in your browser.
